# Candidate proposals

This training-only packet includes source-identified candidate events with a causal decision quote, production structural stop/target menus, and a pass through the environment's static NY-session, open-blackout, fill-bar, and same-session rules. It retains the eligible action fill-bar time and local session-close deadline. The 60-minute proposal TTL is an analysis parameter.

The eligibility pass does not evaluate account-state constraints, policy selection, order contention, or realized actions. Market proposals use the last quote in the completed decision M1 bar; pending-limit proposals use one deterministic source-zone midpoint. The packet does not contain fills, outcomes, returns, or policy value, and includes no report-period rows.

See `candidate_proposal_coverage.csv` for event and rejection counts, and `proposal_ledger_manifest.json` for source, config, local-input, TickBook, and output identities.
