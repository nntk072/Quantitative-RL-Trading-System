# Historical research archive

This archive preserves 247 historical research files and report snapshots that
were previously stored with project-planning and academic work. The former
directory was classified into current research methods, an operational queue,
machine evidence, and personal academic material. The archived files remain
unchanged so their recorded paths, run identities, and contents stay
recoverable; they are not current project instructions or a parallel queue.

- `evidence/` contains the former nested evidence packs, including source
  snapshots, figures, result tables, and run manifests.
- `records/` contains top-level audit scripts, schemas, historical reports,
  and machine snapshots.
- `docs/architecture/migrations/research_directory_classification_20261031.json`
  records every old and new path, SHA-256, reason, and migration type.
- A byte-verified copy of the complete original tree, including personal
  academic files removed from the repository, is preserved at
  `/scratch/work/nguyenl37/agent_plans/Quantitative-RL-Trading-System/docs_thesis_backup_20261031/`
  with its hash manifest alongside it.

and maintained findings, and the
[research execution plan](../../../docs/operations/research_execution_plan.md)
for the active experiment gate. This archive is historical evidence only.
