# Critical symbol source review

This is a scoped review of selected high-risk APIs against their current source
and statically linked test files. It records what the inspected implementations
and test bodies address. Execution claims are limited to the dated review
supplements below; this is not a claim that every listed test ran or covers
every branch. Exact source and test hashes are in
`function_test_reference_map.csv`.

## Session-level source review — 2026-11-03

The refreshed code-review graph resolves 18 direct call sites across 15 nodes
for `detect_session_levels`, including `build_features`, the PO3 stage, the
premium/discount builder, and baseline feature preparation. It links 11 tests.
Source and test bodies confirm that the feature is prefix-causal under the
tested behavior: a prior-date Asian extreme may remain in the 50-observation
rolling window at the next Asian open, but a truncated prefix produces the same
past rows. The 17 tests in `tests/unit/features/test_session_levels.py` passed
inside the existing GH200 allocation. The audit found a naming/documentation
defect, not an established future-data leak: `prev_day_close` holds the prior
bar close, and the `detect_session_levels` docstring describes levels as
per-session even though the implementation rolls across dates. No feature
behavior was changed, preserving the just-verified all-profile source hashes.
