# Entry-idea feature previews

These H1 figures visualize a causal feature preview from the source bars. They
do not show an executed trade or measured model performance. The preserved
source metadata records the data path, selected time, swing anchors, order-block
zone, and plotted retracement levels.

The moved image and metadata paths and checksums are recorded in
[`research_evidence_moves.json`](../../../docs/architecture/migrations/research_evidence_moves.json).
