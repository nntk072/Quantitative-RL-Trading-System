# Candidate proposal ledger

This training-only packet lists bounded setup-price proposals and the production structural stop/target menus available at each M1 decision. It preserves candidate source-event identity and the closed-bar quote timestamp. The 60-minute order TTL is a declared analysis parameter.

The packet does not label fills, stop/target outcomes, returns, or policy value. Market proposals reference the last quote in the completed M1 bar; pending limit proposals use the midpoint of one deterministic source zone where it remains a pending order. No report-period rows are included.

See `candidate_proposal_coverage.csv` for supported candidate coverage and rejection counts, and `proposal_ledger_manifest.json` for source, config, local-input, TickBook, and output identities.
