# Setup-conditioned replay output

The `policy_variant_comparison/` directory retains the canonical C/D testing
equity and policy-metric exports under semantic paths. The complete historical
training and testing exports are preserved in the external checksum archive.
These files are not the human-facing result narrative and should be read with
the [setup-conditioned reasoning protocol](../../../docs/research/setup_conditioned_reasoning_benchmark_protocol.md)
and the [replay interpretation](../../../docs/research/setup_conditioned_policy_replay.md).

The original run paths and exact SHA-256 values are recorded in
[`research_evidence_moves.json`](../../../docs/architecture/migrations/research_evidence_moves.json).
