# Setup-conditioned replay output

The `benchmark_output_20261028/` directory preserves the original C/D training
and testing exports, including plots, summary text, and policy-metric JSON.
The files retain their historical names because they are serialized run
outputs. They are not the human-facing result narrative and should be read with
the [setup-conditioned reasoning protocol](../../../docs/research/setup_conditioned_reasoning_benchmark_protocol.md)
and the [replay interpretation](../../../docs/research/setup_conditioned_policy_replay.md).

The exact file path changes from the earlier research-documents tree are
recorded with SHA-256 values in
[`research_evidence_moves.json`](../../../docs/architecture/migrations/research_evidence_moves.json).
