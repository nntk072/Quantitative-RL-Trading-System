# Evidence

This directory holds machine-readable outputs and complete artifact packs that
support the human-readable research conclusions in [`docs/research/`](../docs/research/README.md).

Each evidence item preserves its original contents. Path changes are recorded
with SHA-256 values under [`docs/architecture/migrations/`](../docs/architecture/migrations/README.md).
Evidence is descriptive and reproducibility material; it does not by itself
establish that a strategy is profitable or generalizes.

## Contents

- [`research/`](research/README.md): generated context counts, feature previews,
  validation records, and model evaluation outputs.
