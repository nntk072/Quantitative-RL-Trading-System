# Project notes vault

Open this directory as an Obsidian vault for human-facing project notes. The
repository remains the source of truth for code, active plans, agent rules, and
research evidence. Graphify's local code graph is stored under the ignored
`outputs/maintenance/graphify/` directory; query it through the Graphify CLI
instead of copying its full symbol graph into this notes vault.

On the Triton x86 login host, the downloaded Obsidian AppImage is kept outside
Git at `outputs/maintenance/obsidian/Obsidian-1.15.1.AppImage`. Launch it with
this directory as the vault when a graphical session is available.
