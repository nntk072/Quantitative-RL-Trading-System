# Support

For reproducible software bugs, documentation problems, and feature proposals,
use the repository's [GitHub issue tracker](https://github.com/nntk072/Quantitative-RL-Trading-System/issues).
Search existing issues first. Include the commit or release, Python and
platform versions, the relevant configuration, a minimal reproduction, and the
expected and observed behavior. Remove credentials and private market or
account data before posting.

Questions about research results should identify the report and its evidence
record. See the [research guide](docs/research/README.md) for interpretation
limits. Security reports must follow [SECURITY.md](SECURITY.md), not the public
issue tracker.

This project does not currently provide paid support, uptime commitments, or
broker execution guarantees.
