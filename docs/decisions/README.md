# Architecture decisions

This directory records durable choices that affect package boundaries,
serialized interfaces, execution assumptions, or project-wide maintenance.
Each decision should state its context, chosen option, alternatives considered,
consequences, and whether it has been superseded.

Research findings and experiment plans belong in `docs/research/`; API field
details belong in `docs/reference/`; agent procedures belong in `.agents/`.
Avoid creating a decision record for a temporary implementation task.
