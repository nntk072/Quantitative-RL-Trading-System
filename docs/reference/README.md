# Reference

Reference pages define stable names, fields, configuration surfaces, and
artifact contracts. They are intended for lookup after reading the relevant
[concept](../concepts/README.md) or [module guide](../modules/README.md).

See the [glossary](../glossary.md) for canonical meanings of domain and
research terms.

## Current contracts

- [Public contracts](public_contracts.md): stable boundaries, internal seams,
  and compatibility surfaces.
- [Public Python API inventory](public_api.md): generated package exports,
  method documentation state, CLI entry points, and internal surfaces.
- [Observation schemas](observation_schemas.md): market sequences, account
  state, masks, and optional context branches.
- [Action schemas](action_schemas.md): discrete, continuous, overlay, and
  setup-conditioned policy outputs.
- [Trade-setup catalog](trade_setup_catalog.md): category order, IDs, masks,
  and serialized compatibility names.
- [Rewards](rewards.md): supported objectives and compatibility limits.
- [Metrics](metrics.md): core performance statistics and their units.
- [Artifacts](artifacts.md): manifests, provenance, and retention concepts.
- [Cache and schema versions](cache_and_schema_versions.md): cache invalidation
  and serialized compatibility rules.
- [Command-line interfaces](cli.md): installed commands and ownership.
- [Configuration defaults](configuration.md): generated dotted-key inventory,
  inferred types, defaults, and owning domains.
- [Model and encoder architectures](model_architectures.md): registered IDs,
  observation inputs, temporal masks, output composition, and checkpoint limits.
- [Feature catalog](feature_catalog.md): feature families, configuration,
  causal timing, normalization, cache, and consumers.
- [Risk and execution contracts](risk_and_execution.md): risk approval, sizing,
  quote sides, fills, and environment ordering.
- [Experiment runs](experiment_runs.md): run identity, worker state, attempts,
  artifact paths, and evidence validation.
- [Manifest schemas](manifest_schemas.md): artifact identity, research JSON
  Schemas, lineage, and compatibility rules.
- [Model catalog](../model_variants.md): generated selectable algorithms,
  encoders, and research comparisons.
- [Configuration](../config.md): configuration ownership and resolution.

Schema pages describe current code contracts. Historical serialized names are
identified as compatibility terms and are not endorsements of their wording.
