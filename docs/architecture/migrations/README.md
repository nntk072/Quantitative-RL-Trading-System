# Compatibility records

Persisted configurations and checkpoints can outlive the code that created
them. Keep only migration records that describe a supported runtime
compatibility path. Research output moves and retired campaign artifacts belong
in neither the current documentation nor the active evidence archive.

See [checkpoint compatibility](../../reference/checkpoint_compatibility.md)
for the current loading rules and [cross-cutting architecture concerns](../cross_cutting_concerns.md)
for compatibility boundaries.
