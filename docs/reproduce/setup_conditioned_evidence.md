# Setup-conditioned replay evidence explorer

**Status:** Exploratory negative result. **Evidence level:** R1 for the full report; selected metrics are inspectable from tracked JSON.

The preserved package contains static figures, summaries, and policy-metric JSON for C/D training and testing. It does not include all equity and trade ledgers needed to regenerate every figure. This page therefore links to the recorded evidence and reports the boundary; it is not a full reproduction.

The recorded 100k-step comparison shows both policies breaching the configured loss limits. Treat this as a bounded negative software/research screen, not evidence that setup conditioning is generally ineffective. The small training budget and incomplete raw outcome ledgers restrict interpretation.
