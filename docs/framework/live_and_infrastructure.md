# Live runtime and infrastructure

The live runtime consumes broker-neutral strategy contracts. Broker-specific adapters live under integrations; compute modules describe devices, resource profiles, and schedulers.

Historical simulation does not guarantee broker behavior. Read [live execution architecture](../architecture/runtime/live_execution), [broker adapter guide](../how-to/add_broker_adapter), [deployment](../operations/DEPLOYMENT), and [operations](../operations/README).
