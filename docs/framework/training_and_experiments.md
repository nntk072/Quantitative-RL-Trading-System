# Training and experiments

Training composes configured data, features, simulation, and a learning backend. Experiments resolve variants and record source/configuration/data identities so comparisons can be reviewed later.

A short training smoke checks software wiring; it does not establish model quality. See [experiment design](../concepts/experiment_design), [run an experiment](../how-to/run_experiment), [training guide](../modules/training), [experiment guide](../modules/experiments), and [experiment comparison tutorial](../learn/tutorials/advanced/experiment_comparison.ipynb).
